### Segunda atividade (?)
Mostrar que $\sin^2 x + \cos^2 x = 1$,  
usando regra da cadeia.
Tome $f(x) = \sin^2 x + \cos^2 x$
$f'(x) = 2\sin x \cos x + 2\cos x (-\sin x) = 0, \quad \forall x \in \mathbb{R}$
$f(x) = K, \quad \text{pois qualquer } K \in \mathbb{R} \quad \forall x \in \mathbb{R}$
Faça $K = 0$, $f(0) = \sin^2 0 + \cos^2 0 = 0 + 1 = 1$.
Logo, $K = 1$.
